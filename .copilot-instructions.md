# GitHub Copilot Instructions for This Project

## Core Guidelines

1. **NEVER create unnecessary documentation files** unless explicitly requested
2. **Only follow the user's explicit instructions** - don't add extra work
3. **Be concise** - implement what's asked, nothing more
4. **Existing files**:
   - SPEC.md - technical specification (user-provided, don't modify)
   - README.md - minimal user guide only
   - Core code in package/, plasma5/, plasma6/
   - Debug scripts: debug.sh, test-widget.sh, watch-logs.sh, validate.sh
   - install.sh and uninstall.sh

## What NOT to Do

- ❌ Don't create SUMMARY.md, PROJECT.md, QUICKSTART.md, TESTING.md, SCRIPTS.md, or similar
- ❌ Don't create "comprehensive guides" or "complete checklists" 
- ❌ Don't write lengthy explanations
- ❌ Don't suggest "would you like me to also..." extras
- ❌ Don't iterate creating more files without being asked

## What TO Do

- ✅ Implement the specific feature/fix requested
- ✅ Keep README.md minimal and functional
- ✅ Make settings persistent properly
- ✅ Follow the SPEC.md requirements
- ✅ Ask if requirements are unclear

## This is a KDE Plasma Widget Project

- Pure QML/JavaScript implementation
- Supports Plasma 5 & 6 from unified codebase
- Configuration must persist via plasmoid.configuration
- Follow standard Plasma plasmoid patterns
